Roulette Even/Odd Tracker

A Microsoft Edge extension for recording roulette results and reviewing historical even/odd frequencies. It does not use AI or claim to predict the next spin.

What it does

  • Records roulette results locally in the extension.
  • Shows even, odd, and zero counts, frequencies, and recent streaks.
  • Supports European roulette (0–36) and American roulette (0, 00, 1–36).
  • Explains the baseline odds so historical patterns aren't mistaken for a guarantee.

Install in Microsoft Edge

  1. Open the GitHub repository and choose Code → Download ZIP.
  2. Extract the ZIP file.
  3. Open edge://extensions and turn on Developer mode.
  4. Choose Load unpacked and select the extension folder.

Open repository on GitHub

Responsible-use note: roulette spins are independent. A run of evens or odds does not make the opposite outcome due. For European roulette, even and odd each cover 18 of 37 pockets; zero is neither. For American roulette, each covers 18 of 38 pockets; 0 and 00 are neither.
